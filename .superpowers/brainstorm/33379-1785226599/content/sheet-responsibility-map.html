收支总览 / 月度汇总

CLI 自动 · 可查可补

收入明细

订单结算、退款、币种和来源由 CLI 获取；缺失或线下调整允许新增“调整记录”。

CLI + SKU 成本

出库产品

订单、SKU、数量、物流由 CLI；单价复用 SKU 成本历史；每条订单保存成本快照。

人工可写 · 核心保留

进货成本

采购、供应商、数量、币种、单价、物流和到货状态继续维护，并形成库存入库。

人工可写 · 合并入口

费用支出 + 前期投入

放在同一资金流水页面，但通过“是否计利润、是否计出资”区分业务效果。

人工可写 · 独立语义

刷单成本

保留独立视图；可关联订单/SKU，刷单收入从真实经营收入和广告转化中排除。

CLI 优先 · 手工兜底

广告充值 / 广告消耗

广告消耗由 CLI；充值流水能取则自动，取不到仍可写。两者分别服务利润和现金。

自动计算 · 人工确认

合伙人分润

期间与利润自动计算；实提金额、日期、状态和冲销可写。默认分成固定 60%/40%。

自动优先 · 可覆盖

汇率换算

每日或每月汇率自动获取；允许登记人工汇率，并保存来源与生效期间。

新增但不替代原 Sheet： “待补 SKU 成本”是出库产品的成本主数据入口；不是另一套出库账。
