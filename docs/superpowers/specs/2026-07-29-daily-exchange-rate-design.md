# 每日汇率同步与回退设计

日期：2026-07-29  
状态：用户已确认

## 目标

每日任务在利润分析前确保报表日期存在 THB/CNY 汇率，避免广告数据正常但利润因 `rate_to_cny` 缺失而中断。

## 规则

1. 每日任务先向 ECB 请求报表日期的 THB/CNY 汇率。
2. ECB 周末、节假日尚未发布新值时，使用 ECB 返回的最近有效参考汇率。
3. 网络失败时，从本地 `exchange_rates` 选择报表日期之前最近一条汇率。
4. 本地汇率距报表日期不超过 7 天时，复制为报表日期汇率并标记 `local_fallback`。
5. 最近汇率超过 7 天或完全不存在时，不生成虚构汇率；广告采集和飞书仍继续，利润保持 `pending_data`。
6. 日志输出 `fresh`、`local_fallback` 或 `unavailable`，不得静默回退。

## 每日顺序

```text
同步/回退汇率
→ Income 扫描（接入后）
→ 广告采集
→ 订单同步
→ 利润分析
→ 报告与飞书
```

## 验收

- 2026-07-28 缺汇率时自动使用 2026-07-27 的最近有效汇率。
- 重新分析后不再出现 `Missing business inputs: rate_to_cny`。
- 利润结果生成。
- 每日任务即使 ECB 网络失败也能使用 7 天内本地值。
- 8 天前的本地值不能被使用。
