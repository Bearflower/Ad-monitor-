# 建议证据展示与占位活动名质量修复设计

## 目标

修复 Shopee 广告优化页面的两个问题：内部审计 JSON 直接铺在页面上且中文被
Unicode 转义；`...` 等占位活动名被误判为有效数据，导致页面错误显示
“缺失：无”。

## 设计

### 可读证据

建议卡默认展示可读中文摘要，覆盖策略观察窗口、最低样本、预算调整幅度、活动
最低 ROAS、快照预算、目标 ROAS 与活动状态。数值按业务单位显示，例如
`0.1` 显示为 `10%`，`5E+2` 显示为 `500`。

完整 `rule_inputs` 仍作为不可变审计证据保留，但放入默认折叠的“技术审计详情”
区域。展示时解析合法 JSON 并以 `ensure_ascii=False` 重新序列化，使中文正常可读；
无法解析的历史值仅进行 HTML 转义，不猜测或丢弃原始内容。

### 数据质量

采集器把空字符串、纯省略号（ASCII 或 Unicode）和纯横线占位符视为无效活动名。
稳定活动 ID、指标和原始快照继续保留，不伪造名称；数据质量增加
`campaign_name` 缺失项并降为 `degraded`，因此禁止激进扩量。

页面和日报遇到无效名称时使用“未获取活动名称（活动 ID）”作为展示回退，不把
占位文本伪装成真实名称。技术审计详情仍可查看页面原始值。

## 数据流与错误处理

页面契约 → 占位名识别 → 保留稳定 ID 与指标 → 标记名称缺失 → 质量降级 →
保守建议 → 中文摘要展示。证据摘要解析失败不影响页面渲染，原始文本仍安全转义。

## 验收

1. 含中文备注的规则输入不再显示 `\\uXXXX`。
2. 默认建议卡不再铺开整段 JSON，完整内容可在折叠详情中查看。
3. `...`、`…`、`—`、`-` 和空名称均产生 `campaign_name` 缺失并降级质量。
4. 缺失名称的活动仍保留稳定 ID、真实指标和快照，页面不显示伪名称。
5. 正常活动名不受影响；HTML 转义与本地安全边界保持不变。
6. 修复后重新采集最近完整业务日并生成 `CURRENT` 日报。

## 非目标

不改变策略阈值、数据库结构、历史审计内容、广告设置或 09:00 调度。
