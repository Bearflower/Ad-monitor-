# 飞书经营日报卡片 v2 设计

## 目标

把现有英文、指标堆叠式日报改为中文经营卡片，展示利润拆解、风险等级、
建议动作及原因，同时保持广告动作由确定性规则产生。

## 安全边界

- `recommendations` 表中的动作继续由 `AnalysisService` 和策略规则生成。
- 已安装的营销、归因、时间序列 Skill 只允许补充说明，不得直接产生或执行
  广告写操作。
- 没有可执行建议时，卡片必须显示“暂不调整”，并给出数据或门禁原因。
- 本次不接入运行时 Agent/Skill 编排，不改变审批和 Live 写入门禁。

## 数据模型

日报读取模型为每个平台增加人民币利润拆解：

- 广告归因销售额
- SKU 成本
- 平台综合费用
- 广告费用
- 其他费用
- 净利润

金额从 `profit_results` 和 `daily_ad_metrics` 聚合。平台费使用
`platform_commission_cny`；SKU 成本和其他费用用利润恒等式在现有字段中解析：

```text
SKU 成本及其他费用
= 广告归因销售额 - 平台费 - 广告费 - 净利润
```

当前数据库尚未在 `profit_results` 分列保存 SKU 成本和其他费用，因此 v2
先将剩余金额显示为“SKU 成本及其他费用”，避免虚构拆分。后续利润结果表增加
分项列后再无损拆分成两行。

## 风险等级

日报取全平台最高风险：

- `高风险` / 红色：熔断、严重告警或净利润为负。
- `中风险` / 橙色：warning 告警或 ROAS 低于目标。
- `待关注` / 黄色：数据待补、库存策略不可用。
- `正常` / 绿色：数据完整且无上述风险。

Markdown 使用中文图标；飞书卡片 Header 使用 `red`、`orange`、`yellow`、
`green` 模板颜色。

## 中文化

平台名称、风险、异常、能力状态、建议动作和原因全部通过显式映射转换：

- `ready` → `已就绪`
- `pending_data` → `待补数据`
- `increase_budget` → `增加预算`
- `reduce_budget` → `降低预算`
- `adjust_roas_target` → `调整目标 ROAS`
- `pause` → `暂停广告`
- `resume` → `恢复广告`

已知规则消息使用中文映射；未知消息保留原文并标记规则代码，避免静默丢失。

## 建议展示

每条建议展示：

```text
建议：降低预算
原因：ROAS 持续低于目标且利润为负
状态：待审批
```

当天没有建议时显示：

```text
建议：暂不调整
原因：尚未满足经过学习期、连续观察窗口和安全门禁的动作条件
```

## 验收

- 报告不再出现 `ready`、`pending_data`、英文风险消息或 `TOP/BOTTOM`。
- Shopee 真实日报显示人民币利润拆解。
- 卡片 Header 颜色与报告风险一致。
- 建议及原因始终存在。
- 原有周报、月报、日报和投递测试全部通过。
