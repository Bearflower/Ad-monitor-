# 每日推送保本目标设计

日期：2026-07-29  
状态：用户已确认业务设计

## 目标

在每日飞书广告经营日报中，把“当前净利润”进一步转化为可执行的保本目标：

- 当前 ROAS；
- 经营保本 ROAS；
- 当前花费下所需保本 GMV；
- 当前客单价；
- 估算保本单量；
- 距离保本还差多少 GMV 和订单；
- 数据可信度和限制说明。

## 业务价值

仅显示净利润为负只能说明“今天亏损”。保本目标回答：

1. 当前投放效率距离不亏钱还有多远；
2. 在广告花费不变时，至少需要多少销售额；
3. 在客单价不变时，大约需要多少归因订单；
4. 当前数据是否足够可靠，可以用于预算决策。

保本目标只用于经营判断和日报提示，不直接触发真实广告修改。

## 已确认口径

采用“经营保本线”，将商品成本视为随销售增长的变动成本。禁止采用“新增销售不增加商品成本”的过度乐观口径。

### 计算输入

按平台每日汇总：

- `spend_original`：平台原币广告花费；
- `gmv_original`：平台原币广告归因 GMV；
- `orders`：平台广告归因订单数；
- `attributed_sales_cny`：广告归因销售额人民币；
- `platform_fee_cny`：平台综合销售费用人民币；
- `sku_and_other_cost_cny`：SKU 成本及随单变动费用人民币；
- `ad_spend_cny`：广告费用人民币；
- `net_profit_cny`：净利润人民币；
- `matched_cost_orders`：成功匹配成本的实际订单数。

### 计算公式

```text
广告前贡献利润 =
    广告归因销售额
  - 平台综合销售费用
  - SKU 成本及随单变动费用

贡献利润率 =
    广告前贡献利润 ÷ 广告归因销售额

经营保本 ROAS =
    1 ÷ 贡献利润率

保本 GMV（平台原币） =
    当前平台原币广告花费 × 经营保本 ROAS

当前客单价（平台原币） =
    当前平台原币 GMV ÷ 广告归因订单数

估算保本单量 =
    向上取整（保本 GMV ÷ 当前客单价）

还差 GMV =
    max(保本 GMV - 当前 GMV, 0)

还差订单 =
    max(估算保本单量 - 当前广告归因订单数, 0)
```

### 不可计算条件

以下任一情况成立时，不输出伪精确数字，显示“暂不可计算”：

- 广告归因销售额小于或等于 0；
- 广告花费小于或等于 0；
- 广告归因订单数小于或等于 0；
- 广告前贡献利润率小于或等于 0；
- 汇率、平台费率或 SKU 成本缺失；
- 平台当日存在多条广告指标，但订单成本无法可靠分摊。

## 数据可信度

保本目标增加三档可信度：

### 已验证

满足：

- 利润计算所有必填项完整；
- 实际成本订单数不低于广告归因订单数；
- 没有成本分配歧义。

可用于人工预算判断，但仍须经过现有审批和 Live 门禁。

### 待对账

满足利润计算，但出现：

- 实际成本订单数少于广告归因订单数；或
- 广告归因订单与平台实际订单存在跨日归因差异。

可以展示估算保本目标，但必须附带差异说明，并禁止用于自动加预算。

### 待补数据

汇率、费率、SKU 成本或订单数不足，保本目标不计算。

## 7 月 28 日示例

输入：

```text
广告花费：THB 210.10
归因 GMV：THB 179.00
归因订单：2
广告归因销售额：CNY 36.06
平台综合销售费用：CNY 8.55
SKU 成本及其他费用：CNY 9.81
广告费用：CNY 42.33
净利润：CNY -24.63
成功匹配成本的实际订单：1
```

结果：

```text
广告前贡献利润：CNY 17.70
贡献利润率：49.08%
经营保本 ROAS：2.04
保本 GMV：THB 428.03
当前客单价：THB 89.50
估算保本单量：5
还差 GMV：THB 249.03
还差订单：3
可信度：待对账
```

## 飞书展示

在“核心经营结果”之后、“平台表现”之前增加：

```text
## 二、保本目标
- Shopee 当前 ROAS：0.85
- Shopee 经营保本 ROAS：2.04
- 当前花费下保本 GMV：THB 428.03
- 当前客单价：THB 89.50
- 估算保本单量：5 单
- 距离保本：还差 THB 249.03 / 约 3 单
- 数据可信度：待对账
- 说明：广告归因 2 单，当前匹配 1 个实际成本订单
```

后续章节顺延编号。

当已经盈利时，仍展示保本线，并将差额改为：

```text
- 已超过保本 GMV：THB X
- 已超过保本单量：约 X 单
```

## 安全规则

- 保本目标是分析结果，不是广告执行建议。
- `待对账` 或 `待补数据` 不得生成加预算建议。
- 不因单日达到保本线自动提高预算。
- 自动策略仍受学习期、连续观察窗口、库存/履约状态、审批和 Live 白名单约束。
- 单量为基于当前客单价和当前商品组合的估算，必须标注“约”。

## 测试与验收

自动化测试：

1. 7 月 28 日样本计算经营保本 ROAS `2.04`。
2. 保本 GMV 为 `THB 428.03`。
3. 保本单量向上取整为 `5`。
4. 还差 GMV 为 `THB 249.03`，还差订单为 `3`。
5. 实际成本订单 `1 < 2` 时可信度为 `待对账`。
6. 成本订单完整时可信度为 `已验证`。
7. 贡献利润率小于等于 0 时显示“暂不可计算”。
8. 零订单、零 GMV、零花费均不发生除零错误。
9. `待对账` 不生成自动加预算建议。
10. 飞书 Markdown 和交互卡片均显示保本目标。

现场验收：

- 使用 2026-07-28 正式数据库重新生成日报；
- 日报显示 ROAS `0.85`、保本 ROAS `2.04`、保本 GMV `THB 428.03`、约 `5 单`；
- 显示“还差 THB 249.03 / 约 3 单”；
- 标记“待对账”，并解释归因 2 单、成本订单 1 单；
- 飞书重发成功。

## 不在本次范围

- 自动修改广告预算；
- 根据单日保本结果暂停广告；
- 预测改变预算后的边际 ROAS；
- 在订单成本不完整时猜测缺失 SKU 成本；
- 将平台归因订单等同于财务已结算订单。
