## 真实广告修改的边界

系统的分析与推荐不需要写权限。修改广告时，确实是通过紫鸟 CLI 控制
真实店铺页面，但“能控制页面”不等于可以安全提交。Live 还必须具备：

1. 已批准且未过期的建议；
2. 当前页面值与审批时预期值一致；
3. 熔断器关闭；
4. 全局写开关和精确目标白名单同时放行；
5. 提交前后审计及失败回滚；
6. 对该平台真实页面选择器完成现场核验。

因此当前代码具备 Shadow 和 Live 安全边界，但
`ADWATCH_LIVE_WRITES=false`。未完成真实页面核验前，不会提交广告修改。

## 最小经营数据

日常人工维护只需：

```csv
data_date,total_product_cost,refund_amount
2026-07-23,120,0
```

订单、GMV 和广告费来自平台。若成本字段代表“除广告费外全部成本”，
可算估算净利润；若只代表进货成本，系统仍需佣金、运费、优惠和退款
才能得到可解释的真实净利润。一天存在多条广告记录时必须使用完整模板，
否则系统拒绝自动分摊。
